# Solidus-X
A high-performance, Layer-1 blockchain core architecture built entirely in Python, featuring secure SHA-256 consensus, cryptographic block validation, and distributed Node-API endpoints.
Solidus-X

Open-Source Proof-of-Stake Blockchain Project

Solidus-X (SLDX) is an open-source blockchain development project focused on building a fast, lightweight and energy-efficient blockchain using Proof-of-Stake consensus.

The project is currently under active development and testing.

«Development status: Prototype / Testnet
Mainnet: Not yet released»

---

🚀 Vision

Solidus-X aims to develop an independent blockchain infrastructure that can support:

- Fast digital transactions
- Low-cost transfers
- Proof-of-Stake validation
- Decentralized node participation
- Developer APIs
- Future Web3 applications

The long-term goal is to create an accessible blockchain platform that developers can inspect, test and build upon.

---

⚙️ Current Technology

The current prototype includes:

- Python-based blockchain core
- SHA-256 block hashing
- ECDSA transaction signature verification
- Transaction processing
- Block creation
- Previous-block hash linking
- Basic node registration
- Flask-based blockchain API
- Chain inspection API
- Initial consensus experimentation

---

🔐 Security

Solidus-X uses cryptographic signatures for transaction verification.

Transactions can be checked using an ECDSA public key and digital signature before being added to the transaction pool.

Security development is ongoing.

Before any mainnet release, the project plans to complete:

- Automated security testing
- Consensus testing
- Multi-node testing
- Network attack testing
- External code review
- Independent security audit
